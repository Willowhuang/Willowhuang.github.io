# Private content stays outside this repository

Do not add anonymous-review titles, author lists, venues, PDFs, or participant media to a public repository, even with `public: false`. Hidden Liquid content still exists in Git history. Keep drafts and identifying metadata in a separate private location until release is explicitly approved.

This directory is ignored (except this note) and excluded from the generated site. It is a reminder, not a secure storage system. The website deliberately contains no identifying submission details. Add only approved public metadata to `_data/publications.yml`.
