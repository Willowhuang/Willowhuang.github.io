# Minimal Light foundation

This site was initialized from [yaoyao-liu/minimal-light](https://github.com/yaoyao-liu/minimal-light), retrieved on October 17, 2026. The original theme uses CC0 1.0 Universal; its license is retained in `LICENSE`.

The original `_layouts/homepage.html`, `_config.yml`, `index.md`, publication include/data, and Gemfile form the baseline import. These are extended or replaced on the feature branch. `_sass/minimal-light-no-dark-mode.scss` is retained unchanged; `_sass/academic.scss` provides the responsive layout and component styles. The reference homepage informed spacing and academic tone only; no reference content, branding, photos, or media were copied.

The site vendors its theme source and builds without a remote-theme download, external fonts, icon libraries, analytics, or JavaScript frameworks. Placeholder SVGs are original illustrations, not photos or evidence of robot behavior.
